### الخطوات التسع — **مؤكَّدة، أعد استعمالها** لأي بند يمسّ حالة الـ popup

هذه هي منصّة الانحدار لمسار «الـ popup يقول الحقيقة» ومسار التعزيز. أي بند يلمس
`GVZ_STATUS` أو `blockedHosts` أو `findVideoFrameId` يُختبر عليها كاملة:

1. **أغلق كل التبويبات المعنية** (ويكيبيديا، يوتيوب، وأي موقع محظور)، ثم أعد
   تحميل الإضافة من `chrome://extensions`.
2. **ويكيبيديا** — والإضافة مفعّلة عامّاً: افتح الـ popup ← **«الإضافة شغالة لكن
   لا فيديو في هذه الصفحة»**. قبل الإصلاح كان يقول «متوقفة». ومُنزلق التعزيز
   **معطَّل** برسالة «لا يوجد فيديو».
3. **صفحة مشغّلها في iframe** (خبر فيه فيديو مضمَّن، أو صفحة فيها مشغّل يوتيوب
   مدمج): افتح الـ popup ← **«الإضافة شغالة على هذه الصفحة»**، والمُنزلق
   **مفعَّل**، وحرّكه ← يعمل على الفيديو داخل الإطار.
4. **موقع محظور بلا فيديو:** احظر ويكيبيديا من الـ popup، أعد تحميل الصفحة، افتح
   الـ popup ← **«الإضافة محظورة على هذا الموقع»** لا «متوقفة». أزل الحظر ← تعود
   «لا فيديو».
5. **موقع محظور فيه فيديو:** احظره ← «محظورة»، والتعزيز يرفض بسبب `blocked`.
6. **الإيقاف العام:** أطفئ «تفعيل الريماب في جميع المواقع» ← «الإضافة متوقفة»
   على كل صفحة، بفيديو أو بدونه. أعد التفعيل ← تعود.
7. **قواعد الموقع وحدها:** أطفئ العام وفعّل قاعدة الموقع ← «تشتغل بقواعد هذا
   الموقع فقط».
8. **يوتيوب — عدم الانحدار:** افتح فيديو ← «شغالة»، والمربعات والعجلة والترجمة
   والجودة والتعزيز كلها كما كانت. وجرّب سطر تعذّر الجودة إن كان مضبوطاً على 4K.
9. **صفحة إخبارية ثقيلة الإعلانات:** افتح الـ popup ← الحالة صحيحة ولا تباطؤ
   (لا إيقاظ للإطارات النائمة). و**صفحة محمية** (`chrome://extensions`) ←
   «هذه الصفحة محمية من المتصفح».

### منصّة اختبار الهجرة — للبند #26 وأي هجرة مخطط لاحقة

الكونسول المستعمل هو **كونسول الـ service worker**: `chrome://extensions` ←
بطاقة الإضافة (**«VIDEO ZONES»** — تغيّر الاسم في #38د، وكان `VIDEO-ZONES`) ←
رابط **service worker**. فتحه **لا يشغّل أي هجرة** — الهجرة لا
تقع إلا على `onInstalled`. **ولا تفتح نافذة الإضافة أثناء الاختبار**: هي تشغّل
هجرة قواعد المواقع وحدها، فتُلبس النتيجة. أما `wheel.actions` فلا يستطيع كتابتها
إلا الـ SW أو صفحة الإعدادات — وهذا ما يجعل ظهورها **دليلاً قاطعاً**.

```js
// (أ) ازرع بيانات قديمة
{
  const all = await chrome.storage.sync.get(null);
  const shards = Object.keys(all).filter(k => k.startsWith("sp:"));
  if (shards.length) await chrome.storage.sync.remove(shards);
  await chrome.storage.sync.set({
    siteProfiles: { "twitch.tv": { enabled: true, mappings: [{ from: "Mouse2", to: "ACTION:TOGGLE_PLAY" }] } },
    settings: {
      blockedHosts: [],
      zones: { enabled: true, fullscreenOnly: false, gridCoverage: "player",
        wheel: { map: {
          "2": { up: ["ACTION:VOLUME:+4"], down: ["ACTION:VOLUME:-4"] },
          "8": { up: ["ACTION:SEEK:+5"],  down: ["ACTION:SEEK:-5"] }
        } } }
    }
  });
  const d = await chrome.storage.sync.get(null);
  console.log("قبل:", { siteProfiles: !!d.siteProfiles,
    شظايا: Object.keys(d).filter(k => k.startsWith("sp:")).length,
    actions: d.settings?.zones?.wheel?.actions === undefined ? "غائبة ✅" : "موجودة ❌" });
}
```

ثم غيّر `"version"` في `manifest.json` (مثلاً `2.11.1`) و**↻ Reload** من
`chrome://extensions` — تغيّر النسخة هو ما يجعل كروم يُطلق `onInstalled` بـ
`reason: "update"`. **ولا تفتح صفحة الإعدادات.** ثم:

```js
// (ب) تحقّق
{
  const d = await chrome.storage.sync.get(null);
  const a = d.settings?.zones?.wheel?.actions;
  const fmt = z => a?.[z]?.map(x => `${x.type}${x.value ?? ""}@${x.key}`).join(" · ");
  console.log("بعد:", {
    "شظية twitch": !!d["sp:twitch.tv"],
    "siteProfiles حُذف": !("siteProfiles" in d),
    "عدد المربعات": a ? Object.keys(a).length : 0,
    "المربع 2": fmt("2"), "المربع 8": fmt("8")
  });
  console.log("بصمة:", JSON.stringify(d).length, "حرفاً · مفاتيح:", Object.keys(d).sort().join());
}
```

المتوقّع: `شظية twitch: true` · `siteProfiles حُذف: true` · `عدد المربعات: 9` ·
`المربع 2: volume+4@up · volume-4@down` · `المربع 8: seek+5@up · seek-5@down`.
وسطر السجل في كونسول الـ SW: `[VIDEO-ZONES] هجرة المخطط update {...}`.
⚠️ **والبادئة `[VIDEO-ZONES]` باقية عمداً بعد #38د** — وسم سجلّ لا واجهة، بينما
اسم البطاقة وقائمة سياق الكونسول صارا **«VIDEO ZONES»**. **فرقٌ مقصود لا سهو.**
**بصمة ثابتة عبر تحديث ثانٍ = لا تكرار عمل.** وأعد النسخة بعد الانتهاء.

## 9. منصّة اختبار Shadow DOM — مؤكَّدة، أعد استعمالها

**البنود 16 و22 و46 و47 كلها مؤكَّدة من المستخدم في المتصفح.** هذه المنصّة تبقى
هنا لأن أي بند يمسّ اكتشاف الفيديو أو الـ overlay يجب أن يُختبر عليها. **مصدر
الفيديو محلي بالكامل — لوحة رسم متحركة تُبَث كـ `MediaStream` — فلا يرثّ برابط
شبكة ميت.** الصق في كونسول أي صفحة:

```js
class VZTestPlayer extends HTMLElement {
  connectedCallback() {
    const sr = this.attachShadow({ mode: "open" });
    sr.innerHTML = `<video controls autoplay muted playsinline
        style="width:640px;height:360px;background:#333"></video>
      <input placeholder="اكتب هنا لاختبار البند 22" style="width:100%;padding:8px;font-size:16px">`;
    const c = Object.assign(document.createElement("canvas"), { width: 640, height: 360 });
    const g = c.getContext("2d");
    let i = 0;
    this.__t = setInterval(() => {
      g.fillStyle = `hsl(${i * 4 % 360},55%,28%)`; g.fillRect(0, 0, 640, 360);
      g.fillStyle = "#fff"; g.font = "700 64px sans-serif"; g.fillText(String(i++), 40, 210);
    }, 100);
    sr.querySelector("video").srcObject = c.captureStream(10);
  }
  disconnectedCallback() { clearInterval(this.__t); }
}
customElements.define("vz-test-player", VZTestPlayer);
const el = document.createElement("vz-test-player");
el.style.cssText = "position:fixed;top:8%;left:8%;z-index:2147483000;background:#000;border:4px solid #22c55e";
document.body.appendChild(el);
```

1. أعد تحميل الإضافة من `chrome://extensions` أولاً.
2. مرّر عجلة الماوس فوق الفيديو داخل الإطار الأخضر ← الشبكة تظهر والأمر ينفَّذ.
3. جرّب النقر ومفاتيح الاختصار فوقه ← تعمل.
4. **البند 22:** انقر في حقل الإدخال داخل المكوّن واكتب أحرفاً وأسهماً ←
   **يجب ألا ينفَّذ أي أمر** ولا يتغيّر الفيديو.
5. انقر خارج الحقل ثم اضغط نفس المفاتيح فوق الفيديو ← تعمل.
6. **البند 46 — دورة ملء شاشة كاملة:** اضغط زر ملء الشاشة في أزرار الفيديو
   الأصلية، اخرج بـ `Esc`، ثم مرّر العجلة ← **الشبكة تظهر**. تأكّد بهذا السطر:

```js
(()=>{const seek=r=>{const h=r.querySelector('.vzWrap');if(h)return h;for(const e of r.querySelectorAll('*'))if(e.shadowRoot){const d=seek(e.shadowRoot);if(d)return d;}return null;};const w=seek(document);console.log('أب:',w?(w.parentNode.host?'#shadow-root في '+w.parentNode.host.tagName:w.parentNode.tagName):'غير موجود','| popover:',w?.getAttribute('popover')??'—','| مفتوح:',w?w.matches(':popover-open'):null,'| صندوق:',w?w.getClientRects().length:0)})()
```

   المتوقّع داخل المكوّن `#shadow-root في VZ-TEST-PLAYER | popover: — | صندوق: 1`،
   وعلى يوتيوب `BODY | popover: — | صندوق: 1`.
7. **البند 47 — أثناء ملء الشاشة نفسه:** اضغط زر ملء الشاشة في أزرار الفيديو
   الأصلية (يكبّر `<video>` نفسه)، و**أنت داخله** مرّر العجلة ← **الشبكة تظهر
   الآن**. المسطرة أثناءه: `popover: manual · مفتوح: true`. وبعد `Esc`:
   `popover: — · مفتوح: false`. (قبل #47 لم تكن تظهر إطلاقاً في هذه الحالة.)
8. **عدم الانحدار:** افتح يوتيوب، وكرّر دورة ملء شاشة كاملة هناك أيضاً —
   ويجب أن يبقى `popover: —` في كل مراحلها، فيوتيوب يكبّر `#movie_player` لا الفيديو.
9. للإزالة: `el.remove()`

> ⚠️ المصدر بثّ حيّ ⇒ `duration === Infinity`، فأوامر `SEEK` لا تعمل عليه
> (البند #34 لا انحدار). اربط أمر **صوت** أو **تشغيل/إيقاف** للتحقق من التنفيذ.
>
> ⚠️ وفي هذه المنصّة الفيديو **ابن مباشر لجذر الظل** (`parentElement === null`)،
> فأمر ملء الشاشة من الإضافة يسقط إلى `<video>` نفسه في `pickFullscreenContainer`.
> هذا هو الطريق الأقصر لإعادة إنتاج **#58** ولاختبار #47 معاً.

## 10. منصّة ملء الشاشة — دائمة، مُلزِمة (قرار 17)

**كل بند يمسّ ملء الشاشة أو اختيار الحاوية يُشغّل هذه المنصّة كاملة.** ليست خطوات
بندٍ مضى: هي منصّة انحدار مثل §8 (حالة الـ popup) و§9 (شجرة الظل). بُنيت من
اختبارَي #58 و#59 اليدويين، وكلاهما **مؤكَّد من المالك 2026-07-30**.

**ما تحرسه:** `pickFullscreenContainer` · `nearestPlayerAncestor` ·
`videoFillsElement` · `VZ_FILL_RATIO` · بوابة `applyFsFillIfNeeded` · المسار
الاحتياطي · `toggleFullscreen` · مسار الزر الأصلي (#17).

### السطران المستعملان

**سطر السمات** — للبوابة، يُلصق **أثناء** ملء الشاشة:

```js
console.log("سمات:", document.querySelectorAll("[data-vz-fs],[data-vz-fs-video]").length, "| CSS:", !!document.getElementById("vz_fs_fill_css"), "| العنصر:", document.fullscreenElement?.tagName + "." + (document.fullscreenElement?.className||"").split(" ")[0]);
```

**وسطر `VZ59`** — للفرع الحاسم وما سيُكبَّر: النسخة الكاملة في
`tools/report-fullscreen-bug.js` (وهي **ما يُلصق قبل الإبلاغ عن أي عطب ملء شاشة**،
قرار 19).

### أ) عدم الانحدار على المواقع

**صفّر أولاً:** `chrome://extensions` ← **⟳ Reload**، وأغلق كل تبويبات الفيديو ثم
افتحها من جديد (سكربت المحتوى القديم يبقى في المفتوحة).

1. **d.tube** (`d.tube/watch/<id>`) — أمر ملء الشاشة من الإضافة ← **الفيديو يملأ
   الشاشة بلا سواد**، و`سمات: 0` و`CSS: false`، والعنصر يحتوي `dtube-player-wrapper`.
   وكرّرها بـ**تنقّل SPA** (نقر فيديو آخر من الرئيسية بلا إعادة تحميل).
2. **يوتيوب** — ملء الشاشة كما كان · `سمات: 0` · واخرج بـ `Esc` ثم مرّر العجلة ←
   **الشبكة تظهر** (عدم انحدار #46).
3. **X — تغريدة فيها فيديو** — `سمات: 0`، وسطر `VZ59` يقول **`الفرع=score`** و
   **`يُكبَّر الآن` = `بعد كومِت ب`**. (خطّ الأساس المقيس في `AUDIT.md` §4ج تحت #59.)
4. **X — التايم-لاين** (`x.com/home`) ← نفس الشيء.
5. **تويتش** و**فيميو** ← ملء الشاشة كما كان · `سمات: 0` في الاثنين.
6. **يوتيوب مرة أخرى:** المربعات والعجلة والترجمة والجودة والتعزيز ← كما كانت.

### ب) البنيتان المحليتان

7. **`tools/manual-59-body.html`** — البنية أ في #59: فيديو ابن `body` مباشرةً ·
   صفحة قصيرة · **زرّ واحد**. الثلاثة معاً هي ما كان يجعل `<body>` يفوز بالسكور.
   **جزء من المنصّة لا ملف مؤقت.** أهون طريقة لفتحها:
   ```

   ```
   ثم `http://localhost:8899/manual-59-body.html`. (فتحها بـ `file://` مباشرةً يعمل
   أيضاً، لكنه يحتاج تمكين **Details ← Allow access to file URLs** على بطاقة
   الإضافة، والخدمة المحلية تتجنّب المساس بالصلاحيات.)
   - اضغط **«اطبع ما سيُكبَّر»** ← **`سيُكبَّر: VIDEO`** (كان `BODY` قبل #59).
   - مرّر العجلة ← الشبكة تظهر. ثم أمر ملء الشاشة ← **الفيديو يملأ الشاشة**.
   - أثناءه: `سمات: 0` · `CSS: false` · `العنصر: VIDEO` — أي أن الإصلاح من
     **اختيار العنصر** لا من قاعدة `!important`.
8. **منصّة الظل §9** — الخطوة 7 فيها تحرس #47 (`popover: manual` أثناء ملء شاشة
   على `<video>` نفسه)، والخطوة 6 تحرس #46.

### ج) الحدّ المعروف — **غير مُختبَر**

9. **حاوية تحمل واجهة في التخطيط** (لائحة تشغيل أو شريط جانبي **داخل** العنصر
   المكبَّر): تمديد الفيديو إلى `100%×100%` يطمس تخطيطها، والبوابة **لا تحمي منه**
   لأن الفيديو فيها فعلاً لا يملأ الحاوية. **هذه الخطوة لم تُنفَّذ بقرار المالك**،
   فتبقى **حدّاً معروفاً غير مُختبَر** — لا يُسجَّل «نجح». من يمرّ بموقع كهذا:
   ألصق سطر `VZ59` وسطر السمات وأبلِغ بالرابط (قرار 19).

## 10ب. منصّة التقديم في البثّ — دائمة (البند #34)

> **كل بند يمسّ `seek()` أو نافذة `seekable` يُشغّل هذه الخطوات كاملة.**
> وهي منصّة دائمة لا قائمة بنودٍ مضت، كأخواتها في §8 و§9 و§10.

**⚠️ اقرأ هذا قبل الخطوات، وإلا قرأتَ تذبذب المشغّل عطباً عندنا:**
**الإرجاع على تويتش لا يُوعَد بحتميّته.** أربعة أرصاد ميدانية متناقضة
(`−8.4s` · `+0.05s` · `−30.84s` · وطلبُ إرجاعٍ انتهى **+18.95s إلى الأمام**)
— **غير مفسَّرة، ولا يُبنى عليها**. **الذي نؤكّده أن طلبنا صحيح ويُرسَل داخل
النافذة، لا أن المشغّل يستجيب.** فخطوة الإرجاع أدناه تُقرأ «أُرسل الطلب» لا
«تحرّك الفيديو حتماً».

**١) تويتش — قناة مسمّاة** (قرار 19: سجّل اسم القناة، **ولا تقس على الواجهة**
`twitch.tv/` فهي تبدّل قناتها فلا يُعاد القياس عليها):
1. افتح `twitch.tv/<قناة مباشرة>` ودع البثّ يعمل.
2. مرّر العجلة لأسفل فوق المربّع **6** (ربطه الافتراضي `SEEK:−5`).
   **المتوقَّع:** لا تجمّد ولا شاشة سوداء. وإن تحرّك الزمن للخلف فحسن،
   **وإن لم يتحرّك فليس عطباً عندنا** — انظر التحذير أعلاه.
3. مرّر العجلة لأعلى فوق المربّع **6** (`SEEK:+5`).
   **المتوقَّع: لا يحدث شيء إطلاقاً** — لا تقديم ولا تجمّد ولا توقّف.
   **هذا هو المقصود:** `duration = Infinity` ونهاية `seekable` **قيمة حدّية**،
   فالتقديم مرفوض بالبناء. ⚠️ **ظهور تجمّد هنا انحدارٌ خطير** — معناه أن شرط
   الثقة في الحدّ الأعلى سقط.
4. تأكّد أن الصوت والتشغيل يعملان بعد الخطوتين، وأن `⏸` لم يظهر من نفسه.

**٢) يوتيوب مباشر (قناة 24/7)** — **شرط القبول هنا صفر تغيّر**:
5. افتح بثّاً مباشراً 24/7 وانتظر انقضاء الإعلان (**الإعلان ليس البثّ**؛ قِيس
   أنه يعلن `duration` منتهية قصيرة فيُقاس شيء غير المقصود).
6. عجلة لأسفل فوق المربّع 6: **يرجع الزمن** — يوتيوب المباشر يعلن
   `duration` منتهية ونافذة DVR حقيقية (قِيس `50380s`).
7. عجلة لأعلى فوق المربّع 6: **يتقدّم الزمن**، ويتوقّف عند حافة البثّ ولا يتجاوزها.
8. **أي اختلاف عن سلوك ما قبل الإصلاح هنا انحدار** — هذه الحالة من الحالتين
   اللتين تُثبتان صفر تغيّر في `tools/test-seek-window.js`.

**٣) فيديو عادي** — الحالة الثانية التي تُثبت صفر تغيّر:
9. افتح أي فيديو عادي (يوتيوب أو غيره) **أثناء تحميله لا بعد اكتماله**.
10. عجلة لأعلى ولأسفل فوق المربّع 6: **يتقدّم ويرجع كما كان قبل الإصلاح بالضبط**.
11. جرّب التقديم قرب نهاية الفيديو: **يتوقّف عند النهاية ولا يتجاوزها**.

**⚠️ وتغيّر سلوك مقصود ومقيس — لا يُقرأ انحداراً:** فيديو من **خادم لا يدعم
نطاقات البايت** يعطي `seekable = [[0, 0]]`. **اليوم** يُحسب الهدف `49.5`
**فيقصّه المتصفّح إلى 0**، فيضيع الموضع ويعود التشغيل من الأول. **وبعد الإصلاح
لا يحدث شيء.** الفرق مقصود بالقياس.

**وما نخسره عمداً — مكتوب كي لا يُعاد النقاش من الصفر:** **التقديم داخل نافذة
DVR على تويتش بعد إرجاع غير مدعوم قصداً.** الرفض شامل للتقديم هناك لأن الحدّ
الأعلى غير موثوق. **ولو أُريد يوماً فثمنه مراقب تجمّد** — آلة غير متزامنة تراهن
على أن المشغّل لا يتعافى، وهو **مقيس على قناة واحدة ونافذة مراقبة واحدة**.

## 10ج. منصّة الحقن اليدوي — دائمة (البند #38ج)

> **كل بند يمسّ `activateOnCurrentPage` أو حقن سكربت في عالم الصفحة يُشغّل هذه
> الخطوات كاملة.** ومنصّة **بيدك** بالضرورة: الرِكاز أعمى هنا (`--load-extension`
> معطَّل، `tools/KNOWN-DEFECTS.md`)، **فالمتصفّح هو الأداة**.

**⚠️ ولا يُحكم بقيمة الجودة وحدها:** قِيس أن **ABR يوتيوب يغيّرها من تلقائه**
(`large ⇒ hd1080` و`⇒ hd720` بلا أي تدخّل). **الحكم على أن الجودة صارت المطلوبة
وبقيت**، لا على مجرّد تغيّرها.

**١) التهيئة:**
1. في صفحة الإعدادات اضبط **الجودة الافتراضية على قيمة صريحة** — مثلاً
   `1080p` — واحفظ. **بلا هذه الخطوة لا شيء يُقاس**: الجودة التلقائية لا تُرسل طلباً.

**٢) يوتيوب بتفعيل يدويّ — شرط القبول الأول:**
2. أعد تحميل الإضافة من `chrome://extensions`، ثم افتح تبويب يوتيوب **جديداً بعدها**
   وشغّل فيديو… ثم **أغلقه**. المقصود صفحة حُمِّلت **بلا سكربت الإضافة**: أسهل
   طريق أن تعطّل الإضافة، تفتح فيديو يوتيوب، ثم تُفعّلها **والتبويب مفتوح**.
3. افتح الـ popup واضغط **«تفعيل يدوي على هذه الصفحة»**.
4. انتظر انقضاء الإعلان، ثم افتح قائمة الجودة في المشغّل.
   **المتوقَّع: الجودة المضبوطة مطبَّقة** — وهذا هو البند.
5. تحقّق أنها **بقيت** بعد نحو نصف دقيقة (لا يعيدها ABR).

**٣) يوتيوب بتفعيل تلقائي — شرط القبول الثاني: صفر تغيّر:**
6. افتح تبويب يوتيوب **جديداً والإضافة مفعّلة** (بلا أي تفعيل يدوي).
7. الجودة تُضبط كما كانت قبل الإصلاح تماماً. **أي اختلاف هنا انحدار.**
8. تنقّل إلى فيديو آخر من داخل يوتيوب: تُضبط للفيديو الجديد كما كانت.

**٤) موقع غير يوتيوب — لا حقن حيث لا فائدة:**
9. افتح موقعاً فيه فيديو **غير يوتيوب** (فيميو أو `d.tube`)، والإضافة معطّلة أو
   الصفحة محمَّلة قبل تفعيلها.
10. اضغط **«تفعيل يدوي»**. **المتوقَّع:** الإضافة تعمل (مربّعات وعجلة)،
    و**لا خطأ في الكونسول**، و`window.__vzQB` في كونسول الصفحة **`undefined`** —
    أي أن سكربت الجودة **لم يُحقن هناك**.
11. وفي كونسول تبويب يوتيوب بعد التفعيل اليدوي: `window.__vzQB` ⇒ **`true`**.

**٥) الإيقاظ — الحالة التي فشلت ميدانياً 2026-07-31، وكلٌّ خطوة مستقلّة بلا «أو»:**

**المسار الأول — الصفحة مفتوحة والجودة تُغيَّر بعدها (فرضية المالك):**
12. افتح فيديو يوتيوب والإضافة مفعّلة، ودعه يعمل.
13. افتح صفحة الإعدادات في تبويب آخر، **غيّر الجودة الافتراضية** إلى قيمة أخرى، واحفظ.
14. ارجع إلى تبويب الفيديو **بلا إعادة تحميل**، وافتح الـ popup واضغط **«تفعيل يدوي»**.
15. افتح قائمة الجودة: **المتوقَّع أن تكون القيمة الجديدة مطبَّقة.**
    ⇒ **نجحت الخطوة: فرضية المالك أُجيبت.** ⇒ **فشلت: أمامنا شيء آخر لم نره، فأبلِغ ولا تُغلق.**

**المسار الثاني — الصفحة أقدم من الإضافة:**
16. عطّل الإضافة من `chrome://extensions`.
17. افتح فيديو يوتيوب ودعه يعمل.
18. فعّل الإضافة **والتبويب مفتوح**، بلا إعادة تحميل الصفحة.
19. اضغط **«تفعيل يدوي»**، ثم افتح قائمة الجودة: **المتوقَّع أن الجودة مطبَّقة.**

**المسار الثالث — ضغطتان متتاليتان (idempotent بالعين):**
20. على صفحة يوتيوب تعمل، اضغط **«تفعيل يدوي»**.
21. اضغطه **مرة ثانية** بعد ثانيتين.
22. **المتوقَّع: لا شيء يتغيّر ولا يتكرّر** — لا وميض قائمة، ولا سطر مكرَّر في الكونسول.

**المسار الرابع — الترتيب الطبيعي بعد الإيقاظ (صفر تغيّر):**
23. افتح تبويب يوتيوب **جديداً والإضافة مفعّلة** — بلا أي ضغط على الزرّ.
24. الجودة تُضبط كما كانت قبل الإيقاظ تماماً. **أي اختلاف انحدار.**

**المسار الخامس — موقع غير يوتيوب بعد الإيقاظ:**
25. افتح موقعاً فيه فيديو غير يوتيوب، واضغط **«تفعيل يدوي»**.
26. **المتوقَّع:** الإضافة تعمل، **ولا خطأ في الكونسول**، و`window.__vzQB` ⇒ `undefined`.

**⚠️ حدّ معلن لا يُصلَح ضمناً:** تبويب بقي مفتوحاً بعد **إعادة تحميل الإضافة**
يحمل `__GVZ_CONTENT_LOADED__` من نسخة ميتة، فحقن `content.js` لا يُعيد تشغيله —
والعلاج إعادة تحميل الصفحة. **خارج نطاق #38ج.**

## 10د. منصّة البوّابة الواحدة — دائمة (البند #64)

> **كل بند يمسّ `extensionActive()` أو `remappingEnabled()` أو `blockedHosts` أو
> أي مدخل ميزة يُشغّل هذه الخطوات كاملة.**

**⚠️ تغيّر سلوك مقصود بطلب المالك — يُقرأ قبل الخطوات فلا يُحسب انحداراً:**
**إطفاء المفتاح الرئيسي صار يوقف الترجمة والمعزّز وClean Player والجودة —
وكانت تعمل قبله.** والمفتاح **افتراضه مُشغَّل** (`!== false`)، فمن لم يفتح إعداده
قط **لا يتغيّر عنده شيء**: الشكل (ب) **صفر تغيّر سلوكي افتراضياً**، والجديد
الوحيد **وجود** المفتاح.

**⚠️ ودلالة «مطفأ»: «لا يُطبَّق من الآن» لا «يُعكَس ما طُبِّق».** جودة ضُبطت قبل
الإطفاء **تبقى** — لا تُرجَع حالة المستخدم إلى الوراء.

**١) الرئيسي مطفأ — كل شيء يتوقّف:**
1. افتح الـ popup وأطفئ **«تشغيل الإضافة»**.
2. افتح فيديو يوتيوب: **الجودة لا تُضبط**.
3. على الفيديو نفسه: **الترجمة بلا تنسيقنا**.
4. حرّك مُنزلق **Sound Booster**: **لا تعزيز**.
5. **Clean Player**: عناصر يوتيوب المخفيّة **تعود ظاهرة**.
6. مرّر العجلة فوق الفيديو: **لا شبكة مربّعات ولا أمر**.
7. حالة الـ popup تقول: **«المفتاح الرئيسي مطفأ — الإضافة متوقفة كلياً»**.

**٢) الحظر وحده — الرئيسي مشغّل:**
8. شغّل المفتاح الرئيسي، واحظر الموقع من الـ popup.
9. الست الخطوات (2–7) **بالنتيجة نفسها**: لا شيء يعمل على هذا الموقع.
10. افتح موقعاً آخر غير محظور: **كل شيء يعمل**.

**٣) الاثنان مطفأان معاً:**
11. أطفئ الرئيسي **واحظر** الموقع: لا شيء يعمل، ولا خطأ في الكونسول.

**٤) «هذا الموقع وحده» — والرئيسي مشغّل:**
12. شغّل الرئيسي، وأطفئ **«تفعيل الريماب في جميع المواقع»**.
13. على موقع بعينه: فعّل **قواعد هذا الموقع** من الـ popup.
14. **المتوقَّع: الإضافة تعمل على هذا الموقع وحده**، وحالة الـ popup تقول
    **«تشتغل بقواعد هذا الموقع فقط»**. ⚠️ **هذا سير عمل قائم لم يُمسّ** — اختفاؤه
    انحدار، لا تحسين.

**٥) التفعيل اليدوي — في كل حالة على حدة:**
15. **الرئيسي مطفأ:** الزرّ **معطَّل ظاهراً** (باهت ولا يُضغط)، وتلميحه يقول
    «المفتاح الرئيسي مطفأ». ⚠️ **زرٌّ يُضغط فلا يحدث شيء انحدار** — درس `skip`.
16. **الرئيسي مشغّل والموقع محظور:** الزرّ يعمل و**يخرق الحظر عمداً** — الإضافة
    تشتغل على الصفحة. **هذا استثناء مقصود لا خرق.**
17. **الرئيسي مشغّل بلا حظر:** الزرّ يعمل كما كان.

**٦) ميزة من كل عائلة بعد التشغيل الكامل — صفر تغيّر:**
18. **الجودة:** فيديو يوتيوب ⇒ الجودة المضبوطة تُطبَّق.
19. **الترجمة:** التنسيق يظهر كما كان.
20. **المعزّز:** المُنزلق يرفع الصوت كما كان.
21. **Clean Player:** العناصر المختارة تُخفى كما كانت.
22. **المربّعات:** العجلة والنقر والمفاتيح كما كانت.

## 13. منصّة القوائم فوق الفيديو — دائمة (البند #65)

> **كل بند يمسّ `videoFromStack` أو `isScrollableLayer` أو `findVideoAtPoint` أو
> مسار العجلة يُشغّل هذه الخطوات كاملة.**

**صفّر أولاً:** `chrome://extensions` ← **⟳ Reload**، ثم أغلق تبويبات الفيديو
وافتحها من جديد (سكربت المحتوى القديم يبقى في المفتوحة).

**⚠️ وقبل الخطوات: اربط أمراً على المربّعين C3 و B3** من صفحة الإعدادات (مثلاً
صوت +4 / −4). **بلا ربط تحتهما لا يقع شيء أصلاً** — الحارس `if (!entry) return`
يخرج قبل كل شيء، وهذا ما جعل أوّل إعادة إنتاج آليّة تفشل.

**١) قائمة الإعدادات في يوتيوب:**
1. افتح `https://www.youtube.com/watch?v=V9PVRfjEBTI` ودع الفيديو يعمل.
2. اضغط زرّ **الإعدادات** (الترس) في المشغّل.
3. مرّر العجلة **فوق القائمة**: **المتوقَّع — القائمة تتمرّر بين خياراتها**،
   ولا تظهر شبكة المربّعات، ولا يتغيّر الصوت.

**٢) قائمة الجودة — وهي التي أبلغ عنها المالك:**
4. من القائمة نفسها ادخل **الجودة**.
5. مرّر العجلة فوقها صعوداً ونزولاً: **تتمرّر بين الخيارات**، ولا شبكة ولا أمر.
6. اختر جودة بالنقر: **تُطبَّق كما كانت** (لم يُمسّ مسار النقر).

**٣) طرفا القائمة — سلوك معلوم مكتوب سلفاً، لا يُقرأ عطباً:**
7. مرّر إلى **أعلى** القائمة ثم عجلة **لأعلى**: **لا يحدث شيء إطلاقاً** — لا
   تمرير (لا مكان) ولا أمر مربّع. ⚠️ **هذا سلوك يوتيوب نفسه بلا إضافة** (قِيس)،
   وليس انحداراً.
8. مرّر إلى **أسفل** القائمة ثم عجلة **لأسفل**: **الصفحة خلف المشغّل تتحرّك** —
   وهو أيضاً سلوك يوتيوب المقيس بلا إضافة.

**٤) العجلة على الفيديو نفسه — الميزة الأساسية، شرط القبول:**
9. أغلق القائمة (`Esc` أو نقرة خارجها).
10. مرّر العجلة فوق **المربّعات المربوطة** (B1 مثلاً): **تعمل كما كانت بالضبط** —
    الشبكة تظهر والأمر ينفَّذ.
11. جرّب المربّعين C3 و B3 **والقائمة مغلقة**: **يعملان** — الحجب مرتبط بالقائمة
    المفتوحة لا بموضعها.

**٥) تويتش — مضيف ثانٍ، وقائمته خارج حاوية المشغّل:**
12. افتح قناة مباشرة، واضغط زرّ إعدادات المشغّل.
13. مرّر العجلة فوق القائمة: **تتمرّر**، ولا شبكة ولا أمر.
14. أغلقها وجرّب العجلة على الفيديو: **كما كانت**.

**٦) موقع بلا قوائم — عدم الانحدار:**
15. افتح `d.tube` أو فيميو (أو `tools/manual-35-volume.html`).
16. مرّر العجلة فوق المربّعات: **كلها تعمل كما كانت** — لا حجب ولا بطء.
17. وافتح صفحة عادية طويلة فيها فيديو مضمَّن، ومرّر العجلة **خارج** الفيديو:
    **الصفحة تتمرّر كما كانت.**

**٧) منصّتا الظلّ وملء الشاشة — الحكم يعبرهما:**
18. شغّل **§9** (شجرة الظل) كاملة: العجلة داخل المكوّن تعمل كما كانت.
19. شغّل **§10** خطوة 7 (`manual-59-body.html`): ملء الشاشة والعجلة كما كانا.

## 14. منصّة مفاتيح العلامة والتعليقات — دائمة (البند #67)

**تُشغَّل كاملةً عند أي تغيير يمسّ مفتاحَي `watermark` و`annotations`** في
`CLEAN_PLAYER_ITEMS` — والحارس الآليّ (`tools/test-clean-player-watermark.js`)
يحرس **شكل** الفصل، وهذه تحرس **ما يراه المستخدم**.

**الموقع:** فيديو **له علامة قناة ظاهرة** — المقيس عليه:
`https://www.youtube.com/watch?v=dQw4w9WgXcQ` — العلامة مربّع `40×40` **أسفل
المشغّل: يميناً في التخطيط الإنجليزي ويساراً في العربي (RTL)**، لأن يوتيوب يعكس
تخطيط المشغّل مع اتجاه الواجهة.

> ⚠️ **العلامة تأتي متأخّرة** — قِيس ظهورها بعد ثوانٍ من بدء التشغيل، لا فوراً.
> **فانتظر ظهورها قبل كل خطوة**، ولا تقرأ اختفاءها قبل أن تراها مرّة.
> ⚠️ **ولا يُوصف موضعها بجهة واحدة:** المشغّل يتبع اتجاه الواجهة، فما هو يمينٌ في
> الإنجليزي يسارٌ في العربي (شاهد عشرون تحت قرار 26).

### أ) قبل أي تغيير — خطّ الأساس

1. افتح الرابط، شغّل الفيديو، **وانتظر حتى ترى علامة القناة** أسفل المشغّل
   (يميناً في الإنجليزي · يساراً في العربي). ⚠️ **تتأخّر بضع ثوانٍ بعد بدء
   التشغيل** — قِيس ظهورها بعد الثانية الثانية لا فوراً، **فلا يُحكم بغيابها قبل
   أن تُرى مرّة**.
2. افتح صفحة إعدادات الإضافة ⇐ **YOUTUBE** ⇐ فعّل **Clean Player** نفسه،
   **وتأكّد أن المربّعين مطفآن**: «Channel watermark» و«Custom video annotations».
3. ارجع إلى الفيديو وأعد تحميله. **المتوقَّع: العلامة ظاهرة.**

### ب) «Channel watermark» وحده — **هذا هو البند**

4. فعّل **«Channel watermark»** وحده، وأعد تحميل صفحة الفيديو.
5. **المتوقَّع: العلامة اختفت.** ⚠️ **وهذا ما كان لا يعمل قبل #67 إطلاقاً.**

### ج) «Custom video annotations» وحده — **تغيّر مقصود**

6. أطفئ «Channel watermark»، وفعّل **«Custom video annotations»** وحده، وأعد التحميل.
7. **المتوقَّع: العلامة ظاهرة.** ⚠️ **وهذا عكس ما كان قبل #67** — كان هذا المربّع
   يُخفيها. **مقصود لا انحدار:** الاسم صار يصف ما يفعله.

### د) المفتاحان معاً

8. فعّل الاثنين، وأعد التحميل. **المتوقَّع: العلامة اختفت** (ولا أثر مزدوج).
9. أطفئ الاثنين، وأعد التحميل. **المتوقَّع: العلامة ظاهرة كما في الخطوة 3.**

### هـ) عدم الانحدار — بقيّة المفاتيح كما كانت

10. فعّل ثلاثة مفاتيح أخرى معروفة الأثر — **«Play button»** و**«Time display»**
    و**«Fullscreen button»** — وأعد التحميل: الأزرار الثلاثة **تختفي من الشريط**.
11. أطفئها: تعود. **وأي خلل هنا ليس من #67** — لم يُمسّ مفتاح غيرهما.

> ⚠️ **حدٌّ معروف بلا حارس (قرار المالك):** إن غيّر يوتيوب أصناف العلامة — أسقط
> `iv-branding` أو جمعها مع صنف آخر — **عاد الازدواج بشكل آخر**، ولا حارس آليّ
> يمنعه. الكشف حينها بإعادة `node tools/bench-clean-player.mjs --overlap`.

## 15. منصّة مسار فشل الحفظ — دائمة (البند #69)

**تُشغَّل كاملةً عند أي تغيير يمسّ `saveSettings` أو `renderAllFromStorage` أو
`flushPendingRevert` أو قناة `onSyncWriteFailed`.**

### افتعال الفشل — بيدك، بسطر جاهز

1. افتح صفحة إعدادات الإضافة، ثم كونسول المطوّر (**⌥⌘I** في ماك · **F12** في ويندوز).
2. افتح `tools/force-sync-failure.js` **والصق محتواه كاملاً** في الكونسول ثم Enter.
3. **يجب أن يطبع:** «✅ مِجَسّ افتعال الفشل فعّال — سيرفض **1** كتابة قادمة…».
   **ولا تُكمل قبل رؤية هذا السطر** — مِجَسّ صامت لا يُعرف أهو عاملٌ أم لا.
   وكل رفض يطبع سطره: «⛔ رُفضت كتابة واحدة عمداً … المفاتيح: settings».
   وللإلغاء يدوياً: `__vzForceFail.restore()`.

### أ) الإرجاع نفسه — مربّع Clean Player

4. اذهب إلى **YOUTUBE**، وانظر مربّعاً **غير مؤشَّر** واحفظ اسمه.
5. الصق المِجَسّ (خطوة 2)، ثم **أشِّر المربّع**.
6. **المتوقَّع ثلاثة معاً:** ⛔ سطر الرفض في الكونسول · **رسالة حمراء** «تعذّر
   الحفظ: تجاوزت عدد عمليات الحفظ…» · **والمربّع يعود غير مؤشَّر**.
   ⚠️ **وقبل #69 كان يبقى مؤشَّراً** — رسالةٌ صادقة تحت ضابطٍ يكذب.
7. أشِّره الآن **بلا مِجَسّ**: يبقى مؤشَّراً (الحفظ نجح). أعِده كما كان.

### ب) نقرتان سريعتان — الثانية لا تُلغى

8. الصق المِجَسّ، ثم **انقر مربّعين مختلفين بسرعة، واحداً تلو الآخر**.
9. **المتوقَّع:** الأول يفشل ويعود غير مؤشَّر · **والثاني يبقى مؤشَّراً** لأن حفظه
   نجح (المِجَسّ يرفض كتابة واحدة). **ولا يُلغى الثاني بإرجاع الأول.**

### ج) الفشل ومودال مفتوح — الإرجاع يُؤجَّل ولا يسقط

10. اذهب إلى **INTERACTION ZONES**، وانقر أي مربّع في الشبكة ⇒ يُفتح المودال.
11. غيّر شيئاً فيه، الصق المِجَسّ، ثم اضغط **حفظ**.
12. **المتوقَّع:** الرسالة الحمراء تظهر · **والمودال يبقى مفتوحاً** (قبل #69 كان
    يُغلق كأن الحفظ وقع).
13. اضغط **إلغاء/إغلاق**. **المتوقَّع: الشبكة تعود إلى حالة التخزين** — أي أن
    الإرجاع **وقع بعد إغلاقه ولم يسقط**.

### د) الـ popup — القناة نفسها

14. افتح الـ popup، ثم كونسولها (زرّ يمين داخل النافذة ⇐ Inspect)، والصق المِجَسّ.
15. اقلب **«تفعيل المربعات»** أو **«الترجمة»**. **المتوقَّع:** سطر حالة أحمر
    **والمفتاح يعود إلى حالته المحفوظة**.

### هـ) عدم الانحدار — بلا مِجَسّ إطلاقاً

16. أعد تحميل صفحة الإعدادات. **المتوقَّع: كل الأقسام تُرسم كما كانت** — الشبكة ·
    المواقع المحظورة · الألوان · التوقيت · الترجمة · Clean Player.
17. غيّر إعداداً من صفحة الإعدادات **وافتح الـ popup**: يعكس التغيير (قناة
    `onChanged` سليمة).
18. افتح **نسختين** من صفحة الإعدادات: غيّر في إحداهما ⇒ **الأخرى تعكس التغيير**.

## 16. منصّة الشارتين — دائمة (البند #71)

**تُشغَّل كاملةً عند أي تغيير يمسّ `showBadge` أو `OVERLAY_PARTS` أو
`showVolumeIndicator` أو `setPlaybackRate` أو `overlay.speedBadge`.**
والسبب أن **المُظهِر صار مشتركاً**: كسرٌ فيه لا يُسقط ميزةً جديدة بل **يُسقط
شارة الصوت القائمة معها** — فالخطوات تُشغَّل على القناتين لا على السرعة وحدها.

**التهيئة:** فيديو يوتيوب عاديّ · والمؤشّر فوق المشغّل · وربطُ عجلةٍ على مربّع
لـ`ACTION:SPEED:+0.25` وآخر لـ`ACTION:VOLUME:+4` (أو استعمل الافتراضيات إن كانت
مربوطة عندك). **وصفحة الإعدادات مفتوحة في تبويب ثانٍ** كي تبدّل المفتاح بلا
إعادة تحميل.

### أ) الافتراض — صفر تغيّر لمن لم يطلب

1. **بلا لمس أي إعداد**، غيّر السرعة بالعجلة على المربّع المربوط.
   **المتوقَّع: لا شارة سرعة إطلاقاً**، والسرعة تتغيّر فعلاً (تحقّق من قائمة
   يوتيوب أو من `document.querySelector("video").playbackRate` في الكونسول).
   ⛔ **ظهورُها هنا يعني أن الافتراض انقلب** — وهو انحدارٌ لا تحسين.
2. غيّر الصوت بالعجلة. **المتوقَّع: رقم الصوت يظهر كما كان بالضبط**، في موضعه
   نفسه وبلونه وحجمه ومدّته. ⛔ أي فرق هنا يعني أن المُظهِر المشترك كسر القائم.

### ب) التشغيل، والقناتان معاً — جوهر «عنصران لا عنصر»

3. في الإعدادات ⇒ **Overlay Timing** ⇒ فعّل **«إظهار شارة سرعة التشغيل»**.
4. ارجع للفيديو وغيّر السرعة. **المتوقَّع: «1.25x» في الزاوية المقابلة لرقم
   الصوت**، ثمّ تختفي بعد المدّة نفسها.
5. ⭐ **غيّر الصوت ثمّ السرعة بسرعة (أقلّ من ثانية بينهما).**
   **المتوقَّع: الاثنتان ظاهرتان معاً في زاويتيهما، ولا واحدة تمحو الأخرى.**
   ⛔ لو اختفت إحداهما أو حلّ نصّها محلّ الأخرى ⇒ **عادت «عقدةٌ واحدة»**.
6. ⭐ **انتظر بعد الخطوة 5 بلا لمس شيء.** المتوقَّع: **كلٌّ تختفي بمؤقّتها**،
   والأخيرة ظهوراً تختفي أخيراً. ⛔ اختفاؤهما معاً في اللحظة نفسها بعد نداءين
   متباعدين ⇒ **مؤقّتٌ واحد يُلغي الآخر**.
7. حرّك النافذة أو غيّر مقاسها والشارتان ظاهرتان. **المتوقَّع: تتبعان الفيديو**
   (حلقة الرسم تعدّهما). ⛔ شارةٌ تبقى معلّقة في مكانها ⇒ **السجلّ لا يراها**.

### ج) القصّ والحدود

8. اضبط السرعة على **4x** ثمّ زدها. **المتوقَّع: «4x» لا «4.25x»** — الشارة
   تقرأ ما صار إليه العنصر لا ما طُلب.
9. وبالمثل عند **0.25x** نزولاً. **المتوقَّع: «0.25x»**.

### د) البوّابات

10. أطفئ **المفتاح الرئيسي** من الـpopup ثمّ غيّر السرعة. **المتوقَّع: لا شارة**
    (ولا يعمل شيء أصلاً). أعِده.
11. **احظر الموقع** من الـpopup ثمّ غيّر السرعة. **المتوقَّع: لا شارة.** أعِده.
12. أطفئ مربّع الشارة وحده. **المتوقَّع: لا شارة سرعة، ورقم الصوت باقٍ يعمل.**

### هـ) المهلة المُورَّثة — والمربّع الذي لا يكذب

13. في الإعدادات، أنزل **«مدة ظهور رقم الصوت»** إلى **0**.
    **المتوقَّع: مربّع شارة السرعة يصير مُعطَّلاً (رماديّاً)**، والسطر تحته
    يقول: «معطّلة الآن: مدّة رقم الصوت صفر…». ⛔ **مربّعٌ يُضغط ولا يفعل شيئاً
    هو الانحدار الذي بُني هذا السطر ضدّه** (قاعدة #24).
14. ارفعها فوق الصفر. **المتوقَّع: المربّع يعود قابلاً للضغط، وحالتُه كما تركتها
    — لم تُغيَّر من تحته.**

### و) وميض يوتيوب — لا تزاحم

15. غيّر السرعة بالعجلة على يوتيوب و**مربّعات Center flash الثلاثة مطفأة**.
    **المتوقَّع: شارتنا وحدها تظهر، ولا وميض «1.25x» من يوتيوب.**
    ⚠️ **وهذا مقيسٌ على الكتابة المباشرة** (قياس المالك 2026-08-02). فإن جاء
    يوماً **محوّل سرعة** لمضيفٍ يفرض نموذجه — كما فرض الصوتَ في #60 — **فقد يعود
    الوميض، ويُعاد القياس ولا يُفترض بقاء النتيجة.**
